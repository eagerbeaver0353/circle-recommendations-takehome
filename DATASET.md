# Seed dataset

This repository includes a small, fully synthetic snapshot of a Lean In
Connect–style community: members, Circles, memberships, the topic taxonomy,
and recent Circle feed activity.

Everything under `data/` is generated by `generate.mjs` — no real people and
no real content. Regeneration is deterministic (`node generate.mjs`).

## Files

| File | Rows | What it is |
| --- | --- | --- |
| `data/topics.json` | 22 | Topic taxonomy Circles and members are tagged with |
| `data/users.json` | 100 | Members: profile fields + stated topic interests |
| `data/circles.json` | 40 | Circles: profile, topic, capacity, and activity aggregates |
| `data/memberships.json` | ~440 | Who belongs to which Circle, and their role |
| `data/activity.json` | ~390 | Recent Circle feed posts with engagement counts |

## Data dictionary

### `topics.json`

| field | type | notes |
| --- | --- | --- |
| `id` | int | |
| `slug` | string | kebab-case, e.g. `negotiation` |
| `label` | string | display name |

| field | type | notes |

| `first_name`, `last_name` | string | synthetic |

| `job_title` | string \| null | |

## Derived signals (not stored as columns)

- **Is a Circle full?** Compare `member_count` to `max_members` (`max_members` may be null).
- **How active is a Circle?** Combine `feed_posts_30d`, `last_activity_at`,
  `chat_messages_30d`, and engagement in `activity.json`.
- **Leaders** come from `memberships` where `role=leader`, joined to `users`.

## Intentionally omitted

- Embeddings / precomputed similarity.
- Raw group-chat message text (only the aggregate `chat_messages_30d` count).

## Planted assessment scenarios

| Scenario | Run for | What's planted |
| --- | --- | --- |
| **Cold start** | `user_id 42` | No memberships, no stated interests, empty profile (`profile_completeness = 0`) |
| **Obvious matches** | `user_id 7` | Interests `leadership-skills`, `public-speaking`; strong active/open Circles `#5 Women Who Lead` and `#6 Speak Up Circle` exist and she has not joined them |
| **Duplicate Circles** | `user_id 15` | Interest `negotiation`; Circles `#10`, `#11`, `#12` are three near-identical active Negotiation Circles — a good list should not return all three |
| **Full / inactive** | `user_id 23` | Interest `getting-promoted`; `#20 The Promotion Path` is **full** and `#21 Career Climbers` is **inactive** — both look like topic matches but should not rank; `#22 Level Up Collective` is the healthy alternative |
